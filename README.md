# Sun Launcher 0.21.0

## Downloads

- [Windows — portable EXE](https://github.com/hemanth-reddy18/Sun-Launcher-Releases/releases/latest/download/Sun-TV-Windows.exe)
- [Mac — universal DMG](https://github.com/hemanth-reddy18/Sun-Launcher-Releases/releases/latest/download/Sun-TV-Mac-universal.dmg)

Windows: open the EXE. Mac: open the DMG and copy Sun Launcher to Applications. Windows is unsigned; Mac is ad-hoc signed and not notarized, so macOS may require approval in Privacy & Security.

Chrome launches the real installed desktop program; Google remains embedded search. Stage uses a horizontal carousel. File View and Music share Stage. Spotify access, direct audio-file downloads and seven verified starter installer downloads are included. Other default web integrations stay inside Sun and share Stage. Explicitly added native programs appear in Stage but retain OS windows. Windows focus/close controls work only for verified supported windows. Ctrl/Cmd + Alt + E returns to Stage when available; shortcut conflicts appear in Settings. Use Settings > Updates for future verified downloads; installation is manual.

This is a workspace preview. VPN tunnelling, universal ad removal, native-app embedding and Dolby Atmos enhancement are not provided. CI validates the universal Mac binary and package startup; physical Mac streaming, audio and long-session performance remain unverified.

Source is privately hosted. This public repository contains release configuration, binaries and [component notices](THIRD-PARTY). Electron binaries contain inspectable JavaScript.
